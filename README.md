# 🌸 TSUNDOKU TOULON

Librairie manga indépendante à Toulon

## 🚀 Installation rapide

1. Installer XAMPP
2. Copier le projet dans `htdocs/`
3. Créer la BDD : `tsundoku_toulon`
4. Importer `database/schema.sql`
5. Accéder : http://localhost/tsundoku-toulon
